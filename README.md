# Annual-Island-Areas-Business-Applications-2005-2025-

## Project Purpose
This project analyzes business application trends in U.S. island territories (2005–2025) and builds a machine learning model to predict future applications.

## Dataset - Link to the dataset: https://www.census.gov/econ/bfs/data/islands.html
Annual Business Applications dataset (BFS Island Areas)

## Python Libraries Used
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Files
- data/ → dataset
- notebook.ipynb → full analysis
- README.md → project description

## Results
- Strong growth in U.S. Virgin Islands
- High volatility in smaller regions
- Model successfully predicts future application trends
